# Contributing

1. Create a focused branch for each change.
2. Add or update tests for behavior changes.
3. Run `pytest` before opening a pull request.
4. Do not include API keys, private security reports, real personal data, or confidential target details in commits or fixtures.
5. Use synthetic examples for tests and clearly label any benchmark dataset that has not been independently reviewed.

## Scope

Keep this project review-first. Do not add automatic exploitation, target scanning, or automatic report closure based solely on model output.
